# Context (short)

- The finalized ingestion logic needed to move out of notebook exploration into `src/`.

# Decision (1-3 bullets)

- Move ingestion logic into `src/ingest/space_weather_k_index.py`.
- Include datetime helpers, HTTP request logic, chunk iteration, disk-writing helpers, and `ingest_k_index_run()`.
- Keep run IDs and chunk tokens generated by helper functions.

# Rationale (why)

- Source modules are reusable and testable.
- Moving logic into `src/` supports entrypoints and future automation.

# Alternatives considered (bullets)

- Keep ingestion logic in notebooks. Rejected because it is harder to test and reuse.

# Consequences (tradeoffs)

- The module owns multiple responsibilities, so helper boundaries matter.
- Later ADRs refine datetime strictness and manifest metadata.
