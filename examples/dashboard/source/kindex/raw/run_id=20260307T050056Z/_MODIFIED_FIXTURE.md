# Modified K-index demonstration fixture

This directory retains the schema, timestamps, location, analysis times, row
presence, and ingestion metadata of a successful BoM Space Weather API run.
Its K-index observation values have been replaced for public presentation.

The values were replaced using a deterministic one-to-one transformation.
Equal source reports therefore remain equal and different reports remain
different, preserving the duplicate and conflict relationships used to
demonstrate the pipeline. The replacement mapping is intentionally omitted.

These values are not historical measurements and must not be used for
scientific analysis or operational forecasting.
